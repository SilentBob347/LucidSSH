# LucidSSH не станет универсальным эмулятором терминала — только SSH

Решение (закрытие OQ-03, 2026-07-16): локальный PowerShell/CMD/WSL-терминал не добавляется — не версионная отсрочка, а осознанная граница scope продукта, зафиксированная как постоянное исключение (CLAUDE.md §6), а не пункт бэклога.

**Почему это не просто «ещё одна вкладка»:** три из четырёх флагманских фич продукта — Страж, Детектор ошибок, Breadcrumb — и дашборд сервера жёстко завязаны на **удалённый SSH exec-канал** и shell-интеграцию, инжектируемую в **удалённый** shell сервера (PROMPT_COMMAND/precmd). Локальный процесс (powershell.exe/cmd.exe/wsl.exe) не имеет этого канала и работает по совершенно другой модели — потребовалось бы дублировать всю эту архитектуру под локальное исполнение, а не просто открыть ещё один тип вкладки. Это увеличило бы scope на сопоставимый со всем текущим продуктом объём работы ради функции, не относящейся к идентичности «SSH-клиент для новичков».

**Рассмотренная альтернатива:** минимальная вкладка без Стража/Детектора (просто локальный shell без флагманских фич) — отклонена, так как непоследовательна с ожиданиями пользователя (одни вкладки защищены, другие — нет) и всё равно требует отдельного пути ввода/вывода.

Решение принято 2026-07-16.
